## Objetivo
Criar um relatório de SLA para a gestão de contratos, porque hoje o processo é manual e demora dois dias por mês.

## Requisitos

**RF-01 — Relatório de SLA por contrato**
O sistema deve mostrar um relatório com o SLA de cada contrato, para o gerente ver quem está estourando.
Critério de aceite: o relatório deve carregar rápido e mostrar os dados corretos.

**RF-02 — Exportação para Excel**
O relatório deve poder ser exportado para Excel.

**RF-03 — Envio automático por e-mail**
O relatório deve ser enviado automaticamente por e-mail toda segunda-feira de manhã.
